# Phase 2 Documentation Intelligence

Adds deterministic, versioned screening rules for commonly expected note sections and coding-readiness indicators. Results are saved as documentation gaps and score snapshots.

## Important limitations
- This is not clinical validation, coding advice, payer policy validation, or a substitute for professional review.
- Keyword absence does not prove inadequate documentation.
- Rules must be specialty-specific, reviewed, and versioned before production use.
- No note text is written to audit logs.
- Production models must be evaluated for false positives, false negatives, specialty bias, and provider workflow impact.
